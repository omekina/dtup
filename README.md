# dtup

Devicetree toolchain with a custom processor for DTS/DTSi files.
Includes the following tools:

- `dtq` &mdash; Querying info from the devicetree source files
- `dtview` &mdash; Viewing the devicetree in-browser (through a custom server and front-end library)

## Installing and running

See the mdBook guide at https://omekina.github.io/dtup/
