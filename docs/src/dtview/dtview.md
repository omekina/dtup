# dtview

dtview is a hot-reloading web app to view the visual representation of the tree and, when needed, report errors or warnings.
The main component is the web server which processes your tree in RAM and serves a HTTP connection, so you can view the tree in real-time in your browser.

Make sure you followed the [installation](../installation/installation.md) before proceeding.

If you are using this tool for the first time, you will need to build it. In such case, follow the [building guide](./building.md).
