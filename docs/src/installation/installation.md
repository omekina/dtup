# Installation

Since binary builds for direct downloads are planned, but not yet available for stability reasons&mdash;you will have to build the project from source yourself.
But don't worry, thanks to Rust's mature ecosystem, that should be a pretty easy task.

We will need to obtain the source code of the dtup project and then we'll need to install the build dependencies.
After that we can jump right to creating device trees.

So go ahead and jump to [the next chapter](./cloning_the_repo.md).
